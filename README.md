# Paradise Nursery

## Project Name
Paradise Nursery Shopping Application

## Project Description
Paradise Nursery is an online plant shopping application built with React.

The application allows users to:
- Browse different categories of houseplants
- View plant names, images, descriptions, and prices
- Add plants to the shopping cart
- Increase or decrease plant quantities
- Remove plants from the cart
- View the total cost of the shopping cart
- Continue shopping from the cart page

## Technologies Used
- React
- React Router
- Redux Toolkit
- React Redux
- CSS
- Vite

## Project Features
- Paradise Nursery landing page
- Plant product listing
- Category-based plant display
- Dynamic shopping cart
- Quantity management
- Total price calculation
- Responsive user interface
